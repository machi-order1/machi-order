# 会計・申告主体とアプリの境界

## 現在進めるアプリ

博多油そば151は現在の MACHI ORDER で運用する。長浜店と白木原店はこの業態の店舗として期間付きで結び付ける。現状は個人事業の申告準備を目標とし、申告者の本人情報が確かになるまで法的な申告主体の割当は行わない。既存の `companies` にある「株式会社MACHI」は運用上の名前であり、現時点の法人の存在や申告主体を表すものではない。

MissMrs.BARicoi と BAR YANEURA はそれぞれ独立したアプリで扱う構想。151の注文・店舗・権限・証憑・会計テーブルへこれらの業態の実データを追加しない。先行して作られた両業態の未連携マスター行は後続の migration で除去済み。

## 将来の統括アプリ

3アプリの上に、売上・経費・利益を各業態別に見る閲覧用アプリを設ける。各アプリは認可済みの集計APIで `business_code`、期間、通貨、税込/税抜、集計定義、確定/参考の区別、更新時刻、データ欠損を返す。統括アプリは原本やスタッフ個人情報を無条件に複製せず、業態別の数字と許可された合計を表示する。通信失敗や未入力をゼロとして扱わない。

将来3業態が同じ法人になる場合は法人の開始日以降を新しい申告主体に割り当て、それ以前の個人事業の帳簿は元の主体に残す。法人設立と資産・在庫・未収未払の引継ぎは別の取引で記録する。申告者が同一人物かどうか未確認の間は、3業態を申告用の数字として合算しない。

## 博多油そば151で自分で確認して申告する前に必要な作業

1. 申告者の法的氏名、事業開始日、青色申告・消費税の状況を確認する。
2. 領収書・請求書と売上・入金・現金・銀行明細の突合を終え、未確認・重複候補を解消する。
3. 複式仕訳、総勘定元帳、試算表、損益計算書、貸借対照表を一致させる。棚卸、固定資産、未払・前払、家事按分、税区分を確認する。
4. 年度を確定して根拠と訂正履歴を保存し、申告書・青色申告決算書などを本人が確認して送信する。

現在の売上・参考利益・経費CSVは帳簿や申告書ではない。未完了の項目を申告可能と表示しない。
