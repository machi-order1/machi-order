# 会計・申告主体と業態の境界

現時点の申告は個人事業として扱う。博多油そば151、BAR YANEURA、MissMrs.BAR icoiは業態として分け、どの個人が申告するかは本人確認が済むまで確定しない。既存の `companies` にある「株式会社MACHI」は運用上の所属であり、現時点の法人の存在や申告主体を表すものではない。

## 原則

- 店舗の営業データは `store_id`、業態は `accounting_businesses`、法的な申告主体は `accounting_subjects` で区別する。
- 業態と申告主体の紐付けは有効期間で記録する。個人から法人へ変わる日以降だけ新しい主体に割り当て、過去の取引を移し替えない。
- 151の長浜店と白木原店は同じ業態に紐付ける。ほかの業態の店舗や口座は、実体が確認できるまで追加しない。
- 申告主体が未確認の取引は申告用の確定集計から除外し、未割当として表示する。本人確認前に異なる個人の事業を合算しない。
- 共通経費は証憑を1件保存し、根拠のある配賦額を業態ごとに記録する。分析上の合計と申告書の合計は区別する。
- 法人成り時の資産・在庫・未収未払の引継ぎは、開始日と個別の移転取引を記録する。過去の帳簿や領収書は元の主体に残す。

## 自分で確認して申告する前に必要な作業

1. 申告者の法的氏名と3業態の帰属、各業態の開始日、青色申告・消費税の状況を確認する。
2. 領収書・請求書と売上・入金・現金・銀行明細の突合を終え、未確認・重複候補を解消する。
3. 複式仕訳、総勘定元帳、試算表、損益計算書、貸借対照表を一致させる。棚卸、固定資産、未払・前払、家事按分、税区分を確認する。
4. 年度を確定して根拠と訂正履歴を保存し、申告書・青色申告決算書などを本人が確認して送信する。

現在の売上・参考利益・経費CSVは帳簿や申告書ではない。上記のうち未完了の項目を申告可能と表示しない。
