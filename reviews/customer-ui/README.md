## 現行の評価

全商品が同じ横並びカードのためおすすめの強弱がなく、スマホでは写真・長い商品名・価格の3列が窮屈。セットは油そばとは別料金であることを強調したい。ドリンクの入口が後ろに位置する。

## 改善案

1. 仮おすすめ：博多油そば、えび塩油そば。大きな写真と「麺量を選ぶ」を表示。人気順位は捏造しない。
2. セット：D チャーシュー丼セットを仮のおすすめにし、追加料金400円〜とサイズ選択を明示。商品・オプションIDと価格計算は既存のまま。推薦対象とセットの表現は実装前に運用と照合する。
3. ドリンク：生ビール、角ハイボール、レモンサワーを見つけやすくする。現在の取得価格は通常600/600/500円。ハッピーアワー開催時だけAPIが返す価格・通常価格・終了時刻を表示し、仮の割引は表示しない。
4. カテゴリは全商品へ到達できる既存動線を維持。比較案の3カテゴリは抜粋であり、実装時に油そば・単品・ソフトドリンクを削除しない。
5. 下部カートは点数・金額・内容確認を明示し、safe-areaに対応。比較案の空カート表示は提案。注文確定まで既存フローにつなぐ。
6. おすすめが売切なら選択不可または別の販売中商品へ差替え。店舗ごとの価格・受付停止・営業時間外を優先。

## 変更予定の境界

- `index.html`：お客様向けの表示・カテゴリ動線のみ。`channel=staff` でも使われるためスタッフ口頭注文画面への波及に注意。
- 新規 `customer-menu.css`：お客様画面専用の見た目を分離する候補。
- 新規の推薦設定ファイル：既存のAPIに推薦項目がないため、初期は店舗別の商品IDを参照する表示設定を検討。商品情報や価格の複製はしない。
- `machi-app.js`、`machi-ui-config.js`、共通CSS、`supabase/**`、会計・厨房ページ：今回の表示改善では変更対象外。
- `sw.js`：管理側と共通。公開段階で最新mainと照合し、キャッシュ更新を一本化。古い版を上書きしない。
- `scripts/qa-v71.mjs`：管理側も更新中。追加の顧客UI検証は専用ファイルを使う。
